스타일 선택지 중 "심플 & 미니멀"을 선택. 구현은 순수 HTML + CSS (JavaScript·npm·빌드 도구 없음).

**Why:** 과도한 프레임워크 도입을 방지하고 사용자 취향에 맞는 결과물 유지.
**How to apply:** 개인/포트폴리오 페이지 작업 시 기본값은 vanilla HTML/CSS. React·Tailwind·애니메이션 라이브러리는 명시적 요청 없으면 추가하지 않음.
